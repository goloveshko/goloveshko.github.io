Fast Chrome Backup

PowerShell • 7-Zip • Automation • CLI

A high-speed, lightweight PowerShell utility for backing up Chrome profiles using 7-Zip. Features smart cache filtering (saving 90%+ space), graceful browser shutdown, auto-language detection, and zero-copy streaming.

View on GitHub

Высокоскоростная утилита на PowerShell для бэкапа и восстановления профилей Chrome с помощью 7-Zip. Фильтрует гигабайты кэша (экономя 90% места), безаварийно закрывает браузер, поддерживает 2 языка и работает за секунды.
